# 知识图谱使用指南

## 📚 概述

知识图谱功能包含两个核心模块：
- **知识图谱可视化**：图形化展示实体和关系网络
- **实体管理**：创建、编辑、删除实体数据

---

## 🚀 快速开始

### 第一步：准备工作

1. **创建知识库**
   - 进入"知识库管理"页面
   - 点击"创建知识库"
   - 填写知识库名称和描述
   - 保存后获得知识库ID

2. **上传文档**
   - 在知识库中上传文档（支持多种格式：PDF、Word、TXT等）
   - 等待文档处理完成

3. **配置实体类型**（可选）
   - 进入"实体类型管理"页面
   - 系统已提供默认类型（如：技术、人物、概念等）
   - 可根据需要创建自定义类型

---

## 📊 使用方式一：自动提取实体（推荐）

### 适用场景
- 文档已上传到知识库
- 需要批量提取实体和关系
- 希望快速构建知识图谱

### 操作步骤

1. **进入可视化页面**
   - 导航到"知识图谱" → "知识图谱可视化"

2. **选择知识库**
   - 在右上角下拉框中选择目标知识库

3. **提取实体**
   - 点击右上角"提取实体"按钮
   - 选择提取范围：
     - **全部文档**：提取该知识库下所有文档的实体
     - **选中文档**：仅提取指定文档的实体
   - 点击"开始提取"
   - 等待提取任务完成（后台异步处理）

4. **查看结果**
   - 提取完成后，点击"刷新"按钮
   - 图谱会自动显示提取的实体和关系

### 提取功能说明

- **实体提取**：自动识别文档中的实体（人物、技术、概念等）
- **关系提取**：自动识别实体之间的关系（创建、依赖、引用等）
- **智能去重**：相同实体自动合并
- **置信度评分**：每个实体和关系都有置信度评分

---

## ✏️ 使用方式二：手动管理实体

### 适用场景
- 需要精确控制实体信息
- 补充或修正自动提取的结果
- 创建特殊类型的实体

### 操作步骤

1. **进入实体管理页面**
   - 导航到"知识图谱" → "实体管理"

2. **选择知识库**
   - 在页面顶部选择目标知识库

3. **创建实体**
   - 点击"创建实体"按钮
   - 填写实体信息：
     - **知识库**：选择所属知识库
     - **名称**：实体名称（必填）
     - **类型**：选择实体类型（必填）
     - **描述**：实体描述（可选）
     - **别名**：多个别名用逗号分隔（可选）
     - **置信度**：0-1之间的数值（默认0.7）
   - 点击"确定"保存

4. **编辑实体**
   - 在实体列表中点击"编辑"按钮
   - 修改实体信息
   - 保存更改

5. **删除实体**
   - 在实体列表中点击"删除"按钮
   - 确认删除（注意：删除实体会同时删除相关关系）

6. **搜索和筛选**
   - 使用搜索框按名称搜索实体
   - 使用类型下拉框筛选特定类型的实体
   - 支持分页浏览

## 🎨 可视化查看图谱

### 基本操作

1. **选择知识库**
   - 在可视化页面顶部选择知识库

2. **查看图谱**
   - 系统自动加载并显示实体和关系
   - 节点 = 实体，连线 = 关系

3. **交互操作**
   - **拖拽节点**：移动节点位置
   - **点击节点**：查看实体详情
   - **缩放**：鼠标滚轮缩放图谱
   - **平移**：拖拽空白区域移动视图

### 高级功能

1. **筛选实体类型**
   - 在工具栏选择"实体类型"下拉框
   - 选择特定类型（如：只显示"技术"类型）
   - 图谱自动更新

2. **搜索实体**
   - 在搜索框输入实体名称
   - 系统高亮显示匹配的实体

3. **切换布局**
   - **力导向布局**：节点自动排列，展示关系网络（默认）
   - **层次布局**：按层级展示，适合树状结构
   - **圆形布局**：节点呈圆形排列

4. **导出图片**
   - 点击"导出图片"按钮
   - 保存当前图谱视图为图片

5. **重置视图**
   - 点击"重置视图"按钮
   - 恢复默认视图状态

## 💡 常见使用场景

### 场景1：从零开始构建知识图谱

**步骤：**
1. 创建知识库
2. 上传相关文档
3. 在可视化页面点击"提取实体"
4. 等待提取完成
5. 查看可视化图谱
6. 在实体管理中补充或修正实体信息

### 场景2：手动构建特定领域的知识图谱

**步骤：**
1. 创建知识库
2. 在实体类型管理中创建自定义类型
3. 在实体管理中手动创建实体
4. 在可视化页面查看图谱结构
5. 根据需要添加关系（通过编辑实体）

### 场景3：分析和探索知识关系

**步骤：**
1. 选择已有知识库
2. 在可视化页面查看图谱
3. 使用筛选功能查看特定类型的实体
4. 点击节点查看实体详情和关联关系
5. 导出图片用于报告或分享

### 场景4：维护和更新知识图谱

**步骤：**
1. 在实体管理中搜索需要更新的实体
2. 编辑实体信息（名称、描述、类型等）
3. 删除过时或错误的实体
4. 添加新发现的实体
5. 在可视化页面验证更新结果

---

## ⚠️ 注意事项

1. **知识库选择**
   - 每个知识库对应一个独立的图谱空间
   - 切换知识库会显示不同的图谱数据

2. **实体类型**
   - 系统类型（如：technology、person）不可删除或修改状态
   - 自定义类型可以自由管理

3. **删除操作**
   - 删除实体会同时删除该实体的所有关系
   - 删除操作不可恢复，请谨慎操作

4. **提取任务**
   - 实体提取是异步任务，可能需要一些时间
   - 大文档会自动分块处理
   - 提取结果的质量取决于文档内容和LLM模型

5. **性能考虑**
   - 可视化默认最多显示100个节点
   - 如果实体过多，建议使用类型筛选缩小范围

## 🔧 故障排查

### 问题1：可视化页面显示"请选择一个知识库"
**解决：** 在页面右上角选择知识库

### 问题2：可视化页面显示"当前知识库中没有实体数据"
**解决：** 
- 检查是否已提取实体（点击"提取实体"）
- 或手动创建实体（在实体管理页面）

### 问题3：提取实体失败
**解决：**
- 检查文档是否已成功上传和处理
- 检查Ollama服务是否正常运行
- 查看后台日志了解详细错误信息

### 问题4：实体类型下拉框为空
**解决：**
- 确保已选择知识库
- 检查实体类型是否已创建并启用
