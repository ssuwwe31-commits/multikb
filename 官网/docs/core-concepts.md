# 核心概念

> 了解 Knowledge Base 的核心概念，帮助您更好地理解和使用系统

---

## 📚 知识库（Knowledge Base）

### 定义

**知识库**是 Knowledge Base 中的核心组织单元，用于管理和组织相关的文档和知识。

### 特点

- **独立存储**：每个知识库拥有独立的数据存储空间
- **数据隔离**：不同知识库之间的数据完全隔离
- **权限控制**：可以设置知识库的可见性和访问权限
- **分类管理**：支持分类和标签管理

### 使用场景

- 按项目组织文档（如"项目A文档"、"项目B文档"）
- 按部门组织知识（如"技术部知识库"、"产品部知识库"）
- 按主题组织内容（如"技术文档"、"产品文档"）

---

## 📄 文档（Document）

### 定义

**文档**是知识库中的基本内容单元，代表一个完整的文件或内容源。

### 文档类型

Knowledge Base 支持 **9种文档格式**：

1. **PDF** - 便携式文档格式
2. **DOCX** - Microsoft Word 文档
3. **PPTX** - Microsoft PowerPoint 演示文稿
4. **Excel** - Microsoft Excel 电子表格
5. **HTML** - 网页文档
6. **Markdown** - Markdown 格式文档
7. **TXT** - 纯文本文件
8. **JSON** - JSON 数据文件
9. **XML** - XML 数据文件

### 文档属性

- **元数据**：标题、作者、创建时间、更新时间
- **分类标签**：支持分类和标签管理
- **状态**：处理中、已完成、失败等状态
- **版本**：文档级版本管理

### 文档处理流程

```
上传 → 解析 → 分块 → 向量化 → 索引存储
```

## 🧩 块（Chunk）

### 定义

**块**是文档被分割后的最小检索单元，是向量检索的基础。

### 分块策略

Knowledge Base 采用**智能分块**策略：

- **基于文档结构**：保留文档的层次结构
- **语义完整性**：尽量保持语义完整
- **大小控制**：默认块大小为 1000 字符（可配置）
- **重叠处理**：相邻块之间可以重叠，提高检索准确性

### 块属性

- **内容**：块的文本内容
- **元数据**：所属文档、位置信息、块类型
- **向量**：块的向量表示（用于语义检索）
- **版本**：块级版本管理

### 块的作用

- **检索基础**：向量检索基于块进行
- **引用溯源**：问答结果可以追溯到具体的块
- **精确更新**：可以单独更新某个块，不影响其他块

## 🔢 向量（Vector）

### 定义

**向量**是文本内容的数学表示，用于语义相似度计算。

### 向量化过程

```
文本内容 → 嵌入模型 → 向量表示（768维）
```

### 向量模型

Knowledge Base 使用多种嵌入模型：

- **文本向量化**：nomic-embed-text（768维）
- **图片向量化**：CLIP、ResNet（512维）
- **多模态融合**：统一的向量空间

### 向量检索

- **相似度计算**：使用余弦相似度计算向量相似度
- **k-NN搜索**：在 OpenSearch 中使用 k-NN 插件进行近邻搜索
- **混合检索**：向量检索 + 关键词检索融合

## 🔍 检索策略

Knowledge Base 提供 **6种检索策略**：

### 1. 向量搜索（Vector Search）

- **原理**：基于向量相似度的语义检索
- **适用场景**：理解查询意图，语义相似的内容
- **优势**：能够理解同义词、相关概念

### 2. 关键词搜索（Keyword Search）

- **原理**：基于关键词匹配的全文检索
- **适用场景**：精确匹配、专业术语
- **优势**：速度快，精确度高

### 3. 混合搜索（Hybrid Search）

- **原理**：向量搜索 + 关键词搜索融合
- **适用场景**：兼顾语义理解和精确匹配
- **优势**：综合两种检索方式的优点

### 4. 精确匹配（Exact Match）

- **原理**：完全匹配查询短语
- **适用场景**：专业术语、固定短语
- **优势**：精确度高

### 5. 模糊匹配（Fuzzy Match）

- **原理**：支持拼写错误和同义词
- **适用场景**：用户输入可能有误
- **优势**：提高召回率

### 6. 多模态检索（Multimodal Search）

- **原理**：文本 + 图片融合检索
- **适用场景**：图文混合查询
- **优势**：支持跨模态检索

## 💬 问答流程

### RAG（Retrieval-Augmented Generation）

Knowledge Base 使用 **RAG** 技术实现知识问答：

```
用户问题 → 检索相关块 → 构建上下文 → LLM生成答案 → 返回结果
```

### 流程详解

1. **问题理解**：分析用户问题，提取关键信息
2. **多路召回**：使用多种检索策略召回相关块
3. **混合排序**：使用 Rerank 模型对结果排序
4. **上下文构建**：选择最相关的块构建上下文
5. **答案生成**：LLM 基于上下文生成答案
6. **引用溯源**：标注答案来源，支持追溯

### 流式输出

- **WebSocket**：实时流式输出答案
- **增量更新**：答案逐步生成，提升用户体验
- **中断支持**：用户可以中断生成过程

## 🔒 安全扫描

### ClamAV 集成

Knowledge Base **唯一集成 ClamAV 病毒扫描**：

- **实时扫描**：文档上传后立即扫描
- **病毒检测**：检测已知病毒和恶意软件
- **恶意脚本检测**：检测 JavaScript、Shell 等恶意脚本
- **状态追踪**：完整的扫描状态记录

### 扫描状态

- **pending**：等待扫描
- **scanning**：扫描中
- **safe**：安全
- **infected**：发现病毒
- **error**：扫描错误
- **skipped**：跳过扫描

## 📊 版本管理

### 双层版本管理

Knowledge Base 提供**文档级 + 块级**双层版本管理：

#### 文档级版本

- 追踪整个文档的变更历史
- 支持文档恢复和对比
- 记录文档的上传、更新、删除操作

#### 块级版本

- 追踪每个块的变更历史
- 支持块级恢复和对比
- 精确到块的版本管理

### 版本操作

- **版本查看**：查看任意版本的内容
- **版本对比**：对比不同版本的差异
- **版本恢复**：恢复到指定版本
