# 功能概览

Multikb Base 提供完整的企业级知识库管理解决方案。

## 核心功能

### 文档处理

- **9种文档格式**：PDF、DOCX、PPTX、Excel、HTML、MD、TXT、JSON、XML
- **智能解析**：结构化解析，保留文档结构
- **智能分块**：基于文档结构的语义分块
- **版本管理**：文档级+块级双层版本管理

### 知识问答

- **多模态输入**：文本、图片、图文混合
- **六种检索策略**：向量、关键词、混合、精确、模糊、多模态
- **流式输出**：WebSocket实时流式问答
- **引用溯源**：完整的引用来源追踪

### 搜索能力

- **文本搜索**：全文检索
- **向量搜索**：语义检索
- **混合搜索**：向量+关键词融合
- **图片搜索**：CLIP向量化，相似图片检索

### 企业级安全

- **ClamAV扫描**：病毒扫描
- **恶意脚本检测**：双重安全机制
- **安全追踪**：完整的安全扫描记录
- **数据隔离**：用户级、知识库级隔离
